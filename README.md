# Movie Rating Analysis

## About the Project
This is my first Python project.
It displays movie ratings and finds the average rating
and the highest-rated movie.

## Technologies Used
- Python
- Git
- GitHub

## Features
- Displays movie names and ratings
- Calculates average rating
- Finds the highest-rated movie

## How to Run
1. Install Python.
2. Download or clone this project.
3. Open the terminal in the project folder.
4. Run:

   python analysis.py
