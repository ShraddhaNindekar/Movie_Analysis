# IMDb Top 1000 Movies Data Analysis Using Python

## Project Overview
This project analyzes the IMDb Top 1000 Movies dataset using Python and Pandas. The goal is to explore movie ratings, genres, directors, and other movie-related information to identify useful insights.

## Objectives
- Explore the structure of the dataset.
- Identify the highest-rated movies.
- Filter movies based on IMDb ratings.
- Check missing values in the dataset.
- Analyze movie counts by genre.
- Calculate average IMDb ratings by director.
- Sort and summarize movie data.

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook / VS Code
- CSV dataset
- Git and GitHub

## Dataset
The dataset contains information about movies, including:
- `Series_Title`: Movie title
- `IMDB_Rating`: IMDb rating
- `Genre`: Movie genre
- `Director`: Movie director
- `No_of_Votes`: Number of audience votes
- `Runtime`: Movie duration
- `Released_Year`: Release year

## Key Analysis Tasks
1. Display the number of rows and columns.
2. Preview the first 10 movies.
3. Select specific columns.
4. Find the top 10 highest-rated movies.
5. Filter movies with ratings above 8.5.
6. Identify missing values.
7. Sort movies by rating in descending order.
8. Count movies by genre.
9. Calculate average ratings by director.

## Skills Demonstrated
- Data loading and exploration
- DataFrame selection
- Filtering and sorting
- Grouping and aggregation
- Missing-value analysis
- Basic data analysis with Pandas

## How to Run
1. Install Python.
2. Install Pandas using `pip install pandas`.
3. Download or place the dataset in the appropriate folder.
4. Update the CSV file path in the Python script.
5. Run the script in VS Code or Jupyter Notebook.

## Conclusion
This project demonstrates fundamental data analysis skills using Python and Pandas. It helps explore movie ratings, compare directors, examine genres, and identify highly rated movies.
